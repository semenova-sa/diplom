# Диплом на тему:
## Мобильное приложение “Мой оператор связи”
(аналог “Мой МТС” или “Мой ТЕЛЕ2” с минимальной функциональностью)

### Контекст: 
Заказчик - компания, предоставляющая услуги сотовой связи физическим лицам. 

Необходимо разработать мобильное приложение, в котором абонент сможет:
- проверить свой баланс,
- просмотреть все тарифы,
- изменить текущий тариф.

### Результат: 
Реализована спецификация требований на разработку мобильного приложения, которое предоставляет следующую функциональность:
- авторизация по номеру телефона
- проверка баланса
- получение информации о тарифе абонента
- получение информации обо всех доступных тарифах
- смена тарифа
- подключение/отключение дополнительных опций к тарифу
