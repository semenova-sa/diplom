# 2\. Use-case

На основе интервью и функциональных приоритетов выделим следующие варианты использования: 

| ID | Use Case | Краткое описание |
| :---: | ----- | ----- |
| UC-01  | Авторизоваться в приложении  | Вход в приложение по номеру телефона с подтверждением по SMS  |
| UC-02  | Просмотреть баланс  | Отображение текущего остатка на лицевом счёте  |
| UC-03  | Просмотреть остатки пакетов  | Отображение остатков минут, SMS и интернет-трафика  |
| UC-04  | Просмотреть информацию о текущем тарифе  | Отображение названия, стоимости и условий текущего тарифного плана  |
| UC-05  | Просмотреть список доступных тарифов  | Отображение каталога тарифов с их условиями и стоимостью  |
| UC-06  | Сменить тариф  | Выбор нового тарифа из каталога и его активация |
| UC-07  | Просмотреть список доступных опций  | Отображение каталога дополнительных услуг  |
| UC-08  | Подключить/отключить опцию  | Активация или деактивация дополнительной опции в один клик  |
| UC-09  | Пополнить счёт  | Оплата счета с помощью банковской карты |
| UC-10 | Подтвердить операцию через 2FA  | Подтверждение для критических операций  |

 

Приложение «Мой оператор связи» взаимодействует со следующими внешними системами:

| Внешняя система | Назначение |
| :---- | :---- |
| Биллинговая система (BSS/OCS) | Хранит баланс, тарифы, опции, историю операций. Обрабатывает запросы на смену тарифа и подключение опций |
| Платёжный шлюз / Эквайринг | Обрабатывает платежи по картам и через СБП |
| SMS-шлюз | Отправляет SMS с кодом подтверждения при авторизации |
| CRM-система | Предоставляет информацию об абоненте (ФИО, контакты, статус) |
| База данных тарифов | Хранит актуальный перечень тарифов и опций, доступных для подключения |

Далее в таблице 1 приведены описания работы сценариев каждого варианта использования. Для критических операций (смена тарифа и подключение/отключение платных опций) требуется двухфакторная аутентификация. Эти операции включают Use Case «Подтвердить операцию через 2FA» (UC‑10), который выполняется перед отправкой запроса в биллинговую систему.
